◆ QUERY FLOW (RAG Pipeline)
1
Frontend: submitQuery()
templates/index.html
Sends {question, search_method, document_ids, session_id} to /api/ask/
↓
2
AskQuestionAPIView.post()
documents/views.py
Validates input, filters documents by owner & status='ready', gets/creates session
↓
3
generate_answer()
documents/services.py
Main RAG orchestrator
↓
4
retrieve_relevant_chunks()
documents/services.py
Routes to search method (default: hybrid), filters by document_ids
↓
5
Search Methods
documents/services.py
simple: Keyword matching
bm25: BM25Okapi scoring
vector: FAISS + OpenAI embeddings
hybrid: BM25 + Vector merged (default)
↓
6
rerank_chunks()
documents/services.py
Post-retrieval reranking: exact match + word overlap + position bonus
↓
7
build prompt + llm.invoke()
documents/services.py
Context + sources + question sent to OpenRouter LLM
↓
8
QuestionHistory.objects.create()
documents/views.py
Stores question, answer, context, source_chunks in session
↓
9
Response
documents/views.py
Returns {answer, sources, search_method, history_id, session_id}
◆ SEARCH METHODS
Simple Search
Keyword matching
Score = word overlap count
Fast, no dependencies
Best for exact matches
BM25 Search
TF-IDF based scoring
rank-bm25 library
Better relevance ranking
Good for semantic similarity
Vector Search
OpenAI embeddings
FAISS index (L2 distance)
Semantic understanding
Finds conceptually similar chunks
Hybrid Search DEFAULT
BM25 + Vector merged
Deduplication by chunk ID
Best of both worlds
+ Post-retrieval reranking
Reranking NEW
Exact match bonus (+10)
Word overlap score
Position bonus (early match)
Applied after retrieval
